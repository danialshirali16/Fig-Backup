Any amount is welcome, including none — if the app is useful to you, that already counts.

## What donations pay for

- The GitHub Actions minutes and macOS/Windows runner time used to build and sign every release.
- The domain and hosting for any future documentation site.
- Test hardware: real Apple Silicon Macs and Windows machines across the versions people actually run.

## Other ways to help that cost nothing

These are worth more than money if you can spare ten minutes:

- **Star the repository** so other people can find it.
- **Report a bug** with your OS, the release tag, and what you expected to happen. Clear bug reports
  are the single most valuable thing you can send.
- **Translate the README** into a language it is missing — see the
  [translated READMEs](readme/) and open a pull request.
- **Answer a question** in [Discussions](https://github.com/danialshirali16/Fig-Backup/discussions).

## Transparency
