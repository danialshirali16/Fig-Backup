## افزودن ۷ زبان جدید به اپلیکیشن (مطابق لیست فیگما)

زبان‌های هدف: **日本語 (ja)، Français (fr)، Deutsch (de)، Español (España) (es)، Español (Latinoamérica) (es-419)، 한국어 (ko)، Português (Brasil) (pt-BR)** — علاوه بر en/fa موجود. همه ۱۴۸ کلید موجود ترجمه می‌شوند؛ هیچ کلیدی بدون ترجمه در هیچ زبانی نمی‌ماند (قانون i18n پروژه).

### ۱. `src/i18n.js` — ساختار و ترجمه‌ها
- اضافه کردن export جدید `LANGUAGES`: لیست متادیتا `{ code, native, rtl }` برای ۹ زبان (fa تنها زبان RTL است)
- حذف کلیدهای `english`/`persian` (جایگزین: native-name lookup)
- افزودن ۷ آبجکت زبان جدید با ترجمه کامل ۱۴۸ کلید (خودم ترجمه می‌کنم — کیفیت مناسب اپ یوتیلیتی؛ اصطلاحات فنی مثل Personal access token مطابق عرف هر زبان)
- جمع‌بندی (pluralization): مکانیزم دوتایی `key`/`keyOne` می‌ماند. برای ja/ko (بدون مفهوم جمع) هر دو کلید متن یکسان می‌گیرند؛ برای fr/es/pt-BR فرم One فقط برای دقیقاً ۱ (صحیح)
- fallback موجود می‌ماند: کلید/زبان غایب → انگلیسی

### ۲. `src/App.jsx`
- Select زبان در Settings: تولید گزینه‌ها از `LANGUAGES` (native name هر زبان، نه ترجمه)
- `rtl = language === 'fa'` → `RTL_LANGUAGES.has(language)` (set از i18n)
- برنچ باینری ویزارد (`language === 'en' ? ... : t('persian')`) → native-name lookup از LANGUAGES
- بقیه (countCopy، Collator با کد زبان، toast position) بدون تغییر — Collator کدهای جدید را می‌پذیرد

### ۳. `figma_backup/core.py`
- `LANGUAGES = {"en", "fa", "ja", "fr", "de", "es", "es-419", "ko", "pt-BR"}` (اعتبارسنجی save_preferences خودکار درست می‌شود؛ تست موجودefa سالم می‌ماند)

### ۴. `src/index.css`
- افزودن fallback فونت‌های CJK به استک (برای ja/ko چون Inter گلیف ژاپنی/کره‌ای ندارد): `Hiragino Kaku Gothic ProN`، `Yu Gothic UI`، `Malgun Gothic`، `Apple SD Gothic Neo` بعد از Helvetica — فقط fallback، اثری روی انگلیسی/فارسی ندارد

### ۵. راستی‌آزمایی
- اسکریپت یک‌بارمصرف node: مقایسه‌ی کلیدهای هر ۹ زبان با en (باید ۱۰۰٪ برابر باشد — بدون fallback خاموش)
- Build + هر دو تست
- مرورگر: سوییچ به ja و pt-BR و fr → رندر + Select فارسی/انگلیسی سالم
- **بیلد نهایی** (`release/Fig Backup.app` + zip)

### ۶. مستندات
- `docs/UI.md` (بخش i18n: لیست زبان‌ها) و `CONTRIBUTING.md` (قانون: هر کلید جدید باید به هر ۹ زبان اضافه شود)
